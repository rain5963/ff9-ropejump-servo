# FF9 Ropejump Servo

このリポジトリは、**FF9（オリジナル版、PS2実機）のナワトビをArduinoとサーボモーターで1000回飛ぶプログラム** です。

## 装置について
- サーボモーターとコントローラーはレゴブロックで固定（一部接着剤を使用）  
- 装置の外観と実際に動かしている様子はこちら： [https://youtu.be/-on52Hd3iG4](#)  

## プログラムの使い方
- `HOME_ANGLE` と `PRESS_ANGLE` を調整すれば、モーターの位置が変わっても使用可能  
- まれに序盤で失敗することがあります  
- 長距離（1599回以降）用に補正を入れていますが、完全ではありません
